# 验证计划

## 需要验证的问题

1. 桌宠提醒是否比普通系统通知更难被忽略。
2. 提醒是否会破坏 coding 心流。
3. 用户是否愿意每天让它常驻桌面。
4. 30 秒到 3 分钟的微运动是否足够低门槛。
5. 用户是否愿意为更多宠物、统计或个性化提醒付费。

## 第一轮验证

对象：自己和 3-5 个长时间电脑工作的人。

周期：3 天。

任务：

- 每天连续运行至少 6 小时。
- 保持默认提醒频率。
- 记录每次提醒的处理结果：完成、稍后、跳过。
- 记录主观感受：烦不烦、有没有帮助、哪些提醒最有用。

## 指标

- 完成率：完成次数 / 总提醒次数。
- 跳过率：跳过次数 / 总提醒次数。
- 稍后后完成率：稍后提醒最终是否完成。
- 留存感：第二天是否主动打开。
- 打扰感：1-5 分，越高越打扰。

## 判断标准

继续做：

- 三天后用户愿意继续开着。
- 完成率超过 50%。
- 打扰感不超过 3 分。
- 用户能说出至少一个它帮到自己的具体时刻。

暂停或转向：

- 大多数提醒都被立刻跳过。
- 用户觉得桌宠遮挡或幼稚。
- 用户只需要普通番茄钟，不需要动作推荐。

## 访谈问题

- 你一般什么时候意识到自己坐太久？
- 普通提醒软件为什么留不住你？
- 你希望它是宠物、教练、机器人，还是极简工具？
- 哪些提醒最有价值：喝水、眼睛、肩颈、手腕、站立？
- 什么情况下你会付费？
