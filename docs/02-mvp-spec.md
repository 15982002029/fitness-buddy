# MVP 需求

## MVP 目标

做出一个可以自己日常使用的桌面小助手，连续运行 3 天，验证它是否真的能让长期电脑工作者更愿意起身活动。

## 功能范围

### 1. 桌面宠物窗口

- 透明或半透明小窗。
- 常驻置顶。
- 可拖动到屏幕边缘。
- 至少 3 种状态：正常、疲惫、开心。
- 不遮挡主要工作区。

### 2. 提醒引擎

- 支持工作时长提醒：25 / 45 / 60 分钟。
- 支持喝水提醒：默认 90 分钟。
- 支持眼睛休息提醒：默认 20 分钟。
- 支持用户操作：完成、稍后提醒、跳过。
- 支持勿扰时间段。

### 3. 微运动推荐

- 从本地动作库选择动作。
- 根据提醒类型选择动作：眼睛、肩颈、手腕、全身、喝水。
- 每个动作只显示：名称、时长、步骤、注意事项。
- 第一版不需要视频，最多用简单图标或动效。

### 4. 简单记录

- 今日完成次数。
- 今日跳过次数。
- 今日喝水次数。
- 连续使用天数。

### 5. 设置

- 工作提醒间隔。
- 喝水提醒间隔。
- 是否开机自启。
- 宠物大小。
- 勿扰时间段。

## 非功能要求

- 后台运行要轻。
- 离线可用。
- 默认不上传用户数据。
- 关闭主窗口后仍可在托盘继续运行。
- 退出要明确，不偷偷留后台。

## 不做

- 不做账号系统。
- 不做云同步。
- 不做社交。
- 不做复杂健身课程。
- 不做大模型依赖。

## 验收标准

- 能在 macOS 上启动一个桌面小窗。
- 可以触发至少 3 类提醒：站立、喝水、眼睛休息。
- 用户点击完成后能更新今日记录。
- 关闭/重开后今日记录仍保留。
- 连续运行 8 小时不明显占用资源。
