# Assets

放桌宠形象、动画、图标、声音等素材。

## 当前使用

- `character/fox.png` —— 「灵狐」形象，Q 版狐娘（480×640 透明 PNG）。
  来源：复用自本人的「打卡器」项目（`~/创业项目/打卡器/src/static/character/base/base_fox_v1.png`），自有资产，风格统一。
  在桌宠里通过 CSS 区分三态：正常（漂浮）/ 疲惫（降饱和 + 💤）/ 开心（提亮 + ✨）。
  局限：目前只有单一姿势，靠 CSS 模拟状态。后续要做真正的多帧/多姿势精灵图才更生动。

## 素材原则

- 第一版优先用自制或可商用授权素材。
- 不直接使用不明授权的动漫角色、游戏角色或开源仓库图片。
- 宠物要小、清楚、低打扰。
