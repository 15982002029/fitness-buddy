# 灵狐动画（按大类）

提醒卡片上会按「大类」显示一个灵狐动画。每个大类放 1-2 个动画就够。
把动画文件按下面的文件名丢进这个文件夹即可，**没有对应文件时会自动回落到静止的灵狐**（`../fox.png`），不会报错。

## 文件名约定

| 文件名 | 大类 | 灵狐在做什么（示意） |
| --- | --- | --- |
| `eyecare.gif` | 护眼养神 | 灵狐闭眼深呼吸 / 远眺 |
| `stretch.gif` | 舒展筋骨 | 灵狐伸展手臂 / 转肩颈 |
| `move.gif` | 起身活动 | 灵狐原地踏步 / 走动 |
| `energy.gif` | 补充能量 | 灵狐喝水 |
| `intense.gif` | 来点强度 | 灵狐举哑铃 / 跳绳 |
| `general.gif` | 兜底 | 通用小动作（可不放，回落静图） |

## 格式建议

- **GIF**（最简单，直接能用）或 PNG 序列/Lottie（以后想要更顺可换）。
- 尺寸建议正方形，透明背景，约 200×200 以上，卡片里显示为 76px。
- 用当初生成灵狐的同一工具出图，保持形象一致。

放好后无需改代码，重启 App 即生效。
